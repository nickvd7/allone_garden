Why AllOne Garden

Everything you need,
nothing you don't

Designed from the ground up for community servers — private, fast, and fully under your control.

🌍

Decentralized by design

Every server is independent. Connect with other gardens through P2P federation — like Mastodon, but for gardening.

🔒

Privacy first

Your data lives on your own hardware — Pi, Mac, PC, or phone. No tracking, no analytics sold to third parties, no cloud lock-in.

🔌

Plugin system

Extend the game with community plugins — achievements, custom plants, voice chat, analytics. All sandboxed and safe.

📱

Mobile ready

Play on iOS and Android as a Progressive Web App (PWA). Add to your home screen in seconds — works offline too.

🌦️

Real seasons

Weather changes daily, crops grow at different speeds depending on conditions. Strategy matters.

🤝

True multiplayer

Visit your neighbours' gardens, trade crops on the marketplace, help them water their plots for XP bonuses.

Get Started

Up and growing
in minutes

One script, one command. Runs on any device you already own.

1

Pick your server device

Raspberry Pi, a spare laptop, your Mac, a Windows PC, or even an Android phone — anything running Linux, macOS, or Android works.

2

Run the installer

A single script detects your platform and sets up Node, PostgreSQL, and a process manager. Pi/Linux also gets Nginx and HTTPS via Let's Encrypt.

3

Invite your friends

Share your server URL. Players register with a username and start planting immediately — no app store needed.

4

Extend with plugins

Browse the community marketplace and drop plugin folders into plugins/community/. Restart to activate.

Installation

Any device, one command

Choose what fits your setup — from a quick local test to a production server with HTTPS.

🫐 Raspberry Pi / Linux

curl -fsSL https://raw.githubusercontent.com/nickvd7/allone_garden/main/install.sh | sudo bash

Installs Node 20, PostgreSQL, Nginx, and a Let's Encrypt certificate. Set GARDEN_DOMAIN for automatic HTTPS.

🍎 macOS

git clone https://github.com/nickvd7/allone_garden
bash install-mac.sh

Uses Homebrew to install Node 20, PostgreSQL, and Redis. Managed by pm2 with auto-start on login.

🪟 Windows

git clone https://github.com/nickvd7/allone_garden
.\start.ps1

PowerShell starter for local dev. For a persistent server use Docker Desktop or WSL2.

🤖 Android (Termux)

git clone https://github.com/nickvd7/allone_garden
bash install-termux.sh

Runs a full Node + PostgreSQL server from F-Droid Termux. Other devices on the same Wi-Fi can connect to it.

🐳 Docker

cp .env.example .env
# set JWT_SECRET in .env
docker compose up -d

Includes PostgreSQL and Redis. Works on any machine that runs Docker — no other dependencies needed.

Play Anywhere

Install on your phone
in seconds

No app store. No download wait. AllOne Garden is a Progressive Web App — open the server URL in your browser and add it to your home screen.

🍎

iOS — Safari

  1. Open the game URL in Safari
  2. Tap the Share button (□↑ at the bottom)
  3. Tap "Add to Home Screen"
  4. Tap Add — done!

⚠️ Must use Safari — Chrome/Firefox on iOS cannot install PWAs.

🤖

Android — Chrome

  1. Open the game URL in Chrome
  2. Tap the ⋮ menu (top right)
  3. Tap "Add to Home screen" or "Install app"
  4. Tap Install — done!

Chrome may also show an install banner automatically at the bottom of the screen.

⚡

What you get

  • ✅ Full-screen, no browser toolbar
  • ✅ Instant launch from home screen
  • ✅ Loads from cache even offline
  • ✅ Works on any phone with a browser
  • ✅ No app store approval needed
  • ✅ Updates automatically
